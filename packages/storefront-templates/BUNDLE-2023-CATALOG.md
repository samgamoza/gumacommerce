## Integration workflow (per template)

1. Extract zip → `reference/{proposedId}-1.0.0/`
2. Port UI → `apps/web/components/storefront/{proposedId}/`
3. Register in `templates.ts`, `patterns.ts`, `template-registry.ts`
4. Add `ShopBusinessCategory` hints + `matchStorePattern()` line
5. Wire `TenantStorefrontHome` + DB `patternId` union
6. Add demo tenant in `demo-data.ts`
7. Document in `packages/storefront-templates/README.md`
8. Build verify + demo URL 200
